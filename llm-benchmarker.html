🔌 Runner / Fournisseur
🧠 Modèle

Contexte Auto : Ollama conserve son réglage. Le contexte du runner chargé est relevé pendant le test ; le maximum du modèle est affiché séparément.

Dense : calcul dense à chaque token. MoE : une partie des experts est activée par token. Le nombre de paramètres actifs, la quantification, le contexte et la bande passante influencent le débit ; MoE ne garantit pas une vitesse supérieure.

Le même lancement peut mesurer génération et agentique. Gardez les catégories de texte souhaitées et choisissez les épreuves ci-dessous. Chaque épreuve utilise un cadre système, des outils natifs et un évaluateur indépendant.

Par épreuve : 12 tours modèle, 24 appels, 4 minutes, budget de sortie cumulé. Les fichiers restent dans un dossier temporaire dédié ; aucun shell, réseau d’outil ni document personnel. La clarification et le changement d’objectif utilisent un utilisateur scripté. Ces épreuves LLMB ne sont pas les benchmarks officiels BFCL ou τ-bench.

ℹ️ À propos de LLM Benchmarker

LLM Benchmarker v0.09.0 est une maquette fonctionnelle permettant d'évaluer les performances de modèles LLM locaux et externes directement depuis le navigateur.

Runners locaux supportés :
🦙 Ollama — http://localhost:11434
🏠 LM Studio — http://localhost:1234
🦔 llama.cpp (server) — http://localhost:8080

APIs externes :
OpenAI, Mistral AI, Anthropic Claude (nécessitent une clé API)

Métriques collectées :
Tokens générés · Tokens/seconde · Temps de 1er token (TTFT) · Temps total · Température · Modèle

💾 Stockage local : localStorage — vos données restent sur votre machine.
🔑 Les clés API sont stockées localement et jamais transmises à des tiers.

🔌 Test de connectivité

Vérifiez que vos runners locaux sont accessibles.

🔑 Clés API

Ces clés sont stockées uniquement dans votre navigateur (localStorage).
